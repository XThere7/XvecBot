# BotBase documentation

BotBase turns your business documents, website pages and public social posts into an AI assistant that answers customer questions with citations.

## Start here

1. Create an account and a workspace.
2. Upload a PDF, TXT or DOCX file, or connect a website.
3. Wait for the knowledge to finish indexing.
4. Create an agent and test it.
5. Generate an embed token and put the widget on your site.

## What you can do

- Upload documents and link knowledge to a workspace.
- Connect a website and keep it refreshed.
- Build agents with their own prompt, model, temperature and welcome message.
- Embed an agent on a website or share a hosted chat link.
- Use the Developer API with a workspace-scoped API key.

## Need help?

Use the navigation to open the model, widget or developer guides. For account or billing questions, contact support through the dashboard.
